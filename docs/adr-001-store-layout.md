# Adr 001 store layout

* работа до истечения ttl;
* работа в памяти;
* работа с префиксом;
* работа на каждом запросе;

## поведение

Библиотека не делает ничего лишнего: только чтение и запись по ключу.
Ошибки складываются в исключения `Cache\Store\Exception`, TTL считается по часам,
которые передали снаружи.

## пример

```php
$store->set('page:42', $value, 600);
```
